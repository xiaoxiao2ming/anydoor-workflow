# client-base 图标体系 · 交付规格书

> 交接文档：主开发进程可直接按本文档取用素材、生成 .ico、集成进应用。
> 定稿时间：2026-10-07。所有素材位于 `<logo-assets-dir>\client-base-icons_assets\`。
> 全部迭代过程稿见同目录画布 `client-base-icons.miora`。

## 1. 定稿清单（以这三件为准）

| 角色 | 文件 | 规格 | 用途 |
|------|------|------|------|
| 主 Logo（锚点） | `logo-FINAL-v11-transparent.png` | 1536x1536，透明背景 PNG | About 页、启动页、安装包品牌位；透明底可任意合成 |

注意：三张源图均为 1536x1536 位图，**集成前必须由开发侧缩放出多尺寸 ico**（见第 5 节），不要直接拿 1536 当窗口图标。

## 2. 设计规格

### 2.1 主 Logo 构成
- 主体：手写水墨圆环（浓墨、飞白质感）+ 四条笔触腿（左右镜像对称：左二右二，向外撇）
- 辅助元素：圈后淡墨残影、飞溅墨点、宣纸质感
- 语义：圆 = 画布/工作流闭环；四腿 = 底座（client-base 的「base」）；整体站姿端正
- 硬约束（改版时不可破坏）：
  1. 腿必须正好 4 条，左右对称
  2. 风格锁定传统水墨（enso 笔触 + 宣纸底），不得改成线稿/科技风
  3. 标记无任何文字、无水印

### 2.2 配色 token

| Token | 色值 | 用途 |
|-------|------|------|
| 宣纸白（icon 底砖） | `#F5F3EE`（近似，含纸纹） | 快捷方式/文档图标的底色，保证深色桌面上黑墨可读 |
| 浓墨（主体） | `#1A1A1A` ~ `#3B3B3B`（墨阶渐变） | 圆环与腿 |
| 朱砂红（印章点缀） | `#C3272B` | 印章，唯一彩色点缀，不得挪作他用 |

### 2.3 衍生图标规格
- 快捷方式：宣纸白圆角方砖 + 居中墨标记 + **左下角**快捷方式箭头角标（白底小方砖 + 黑色弧形箭头）+ 右下朱砂印
- 文档图标：竖版纸张 + **右上折角** + 居中墨标记 + 右下朱砂印 + 轻投影
- 两件衍生上的墨标记与主 Logo 为同一笔触形态，不得单独重绘

## 4. 集成规则

1. **主 Logo 透明底版本是唯一锚点**：任何物料（安装包 banner、About 页、网站 favicon 源）都从 `logo-FINAL-v11-transparent.png` 派生，不得用文字描述重画。
2. **快捷方式/文档图标不改标记**：只允许整体缩放、加投影；不得改墨色、改腿数、加文字。
3. **朱砂红印章是体系唯一彩色**：应用内如需呼应品牌色，用 `#C3272B`；不要引入新的彩色。
4. 版本记录：用户定稿语义为「v11 左右对称 + 透明底」，历史决策链见画布；后续改版需在画布上继续迭代，保持版本号递增。

## 5. 开发侧待办（生成 .ico）

Windows 桌面图标建议从定稿源图生成多尺寸 ico：

```
尺寸集：16 / 24 / 32 / 48 / 64 / 128 / 256
快捷方式 → icon-shortcut-clean.png → client-base-shortcut.ico
文档类型 → icon-document-clean.png → client-base-doc.ico
应用本体 → logo-FINAL-v11-transparent.png（需先合成到宣纸白圆角砖上再缩放）→ client-base-app.ico
```

- 小尺寸（16/24/32）下飞白和残影会糊，若可读性不足，允许在小尺寸版去掉残影与墨点、只留「圈 + 四腿」主结构
- 透明底主 Logo 直接缩到小尺寸会失去白底支撑，**必须先垫宣纸白砖**（参考快捷方式图标的底砖做法）
