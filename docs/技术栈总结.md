# 技术栈总结

> 画布式 AI 工作流桌面应用 · 版本 0.00.x

## 总体架构

| 层 | 技术 | 职责 |
|---|---|---|
| 桌面运行时 | Electron 44 | 文件 IO、定时任务、网页抓取、本地大模型推理 |
| 桥接层 | preload / contextBridge | 渲染与主进程类型安全的 IPC |
| 前端框架 | React 18 + TypeScript 5.7 | 函数组件 + hooks，全量 tsc 门禁 |
| 画布引擎 | @xyflow/react (React Flow v12) | 节点、连线、锚点 |
| 状态管理 | zustand 5 | 单例 store，节点即表（Schema + records + config） |
| 表格 | AG Grid 32 | 数据表格行编辑与渲染 |
| 富文本 | TipTap 2.11 | 文档类节点编辑内核 |
| 持久化 | sql.js 1.12 (IndexedDB) + .wfc (JSON 工程文件) | 数据落地与画布存取 |
| 本地推理 | node-llama-cpp + GGUF | 离线大模型会话池、任务分层路由 |
| 外部模型 | OpenAI 兼容 API | 可选云端推理通道 |
| 文档处理 | docx / mupdf / pdf-lib / OnlyOffice | Word/PDF 生成与编辑 |
| 构建 | Vite + vite-plugin-electron + electron-builder | 渲染与主进程同链构建打包 |
| 测试 | Vitest | 单元与集成测试 |

## 设计原则

- **单源真相**：store 集中状态，派生数据（连线 → 上游输入）由关系计算，避免双源不一致。
- **能力下沉**：文件、网络、模型推理放主进程；渲染层只做编排与视图。
- **意图引擎**：规则正则优先，本地 LLM 兜底路由，白名单校验保证安全。
- **本地优先**：核心 AI 能力离线可用，外部 API 可选。

## 主要能力

27 种节点覆盖数据表、参数表、网址监控、Excel转DXF、PDF 生成/瘦身/替换/转 Word、Word/Excel 模板域回写、OnlyOffice 内嵌编辑、AI 分析等，支持对话式搭建工作流与 `{{field}}` 内联引用体系。
