# 提示词对照表（总索引）

> 2026-10-05 建。本表是**命令 → 提示词文件**的唯一入口。
> 规矩：**一个命令一个 md**，命令的语义、输入输出、约束全写在自己那份 md 里，
> 本表只做索引与状态登记，不复制内容（复制即分叉，分叉即对不上）。

---

## 1. 怎么用这张表

1. 先在下表找到命令 → 打开对应 md → 把 md 里的提示词整段喂给 AI
2. 命令名即调用名，全小写无空格，用 `.` 分段（`ooec.col.set`）
3. 改命令语义时**先改对应 md**，再回本表改「最后更新」日期
4. 新增命令必须同时在本表登记，否则等于没上线

## 4. 命名对照

| 命令前缀 | 对应节点 kind | 业务含义 | 依据 |
|---|---|---|---|
| `ooec` | `chapter`（章节工作簿） | **O**ffice **O**bject **E**xcel + **C**ost（造价材料表） | `需求文档_C端Office编辑器.md` §2.2 流程模型里的「材料表(Excel)」 |

`ooec` 是**提示词侧的简称**，代码里节点 kind 仍叫 `chapter`（章节工作簿）。
两者是同一个东西的两种叫法：代码按能力命名（章节编排），提示词按业务命名（造价材料表）。
**不要因为名字不同就以为有两个节点。**

## 5. 未登记的command 一律不认

若确实需要新命令：先写 md → 再登记本表 → 最后才允许调用。
