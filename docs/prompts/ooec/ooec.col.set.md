# ooec.col.set —— 设定列类型

> 状态：规格已定，未实现
> UI 等价物：**右键列头 → 类型菜单**

---

## 1. 用途

给某一列设定类型。这是「第二列之后为自定义菜单（自定义列）形式」的执行入口。

---

## 2. 提示词

```
把 ooec 材料的{工作表} 表第 {列字母} 列的类型设为 {类型 key}，
列头文字改为「{列名}」。

回报：改前列类型、改后类型、是否影响已有数据的校验结果。
```

---

## 3. 右键菜单形态

在任意列头上右键，弹出类型菜单：

```
┌─ 列类型 ──────────────┐
│ ○ 名称列name         │
│ ○ 材料库对照列    matlib   │
│ ○ 参数引用列      param    │
│ ○ 单位列          unit     │
│ ○ 数量列          qty      │
│ ○ 系数列          coef     │
│ ○ 备注列          remark   │
│ ────────────────────── │
│ ○ 单价列          price    │
│ ○ 金额列          amount   │
│ ○ 规格型号列      spec     │
│ ○ 品牌列          brand    │
│ ○ 损耗率列        loss     │
│ ○ 分组列          group    │
│ ○ 自定义文本      text     │
│ ────────────────────── │
│ ✕ 清除类型              │
└──────────────────────────┘
```

- 当前列的类型打勾（`○` 是未选中的单选样式，实际渲染用 `✓`）
- 悬停显示该类型的一句话说明（`hint` 字段）
- 选「清除类型」= 退回 `text`

---

## 4. 列头兜底匹配（重要）

**列类型存在节点配置里，不落 xlsx**（理由见 `ooec.col.types.md` §5）。
所以文件换节点打开时类型会丢 —— 靠**列头文字**兜底：

| 情况 | 处理 |
|---|---|
| 配置里有该列的类型 | 用配置的（**权威**） |
| 配置里没有，但列头文字能匹配上某个类型 | 用匹配结果，并在回报里说明「按列头推断」 |
| 两者都没有 | 回落 `text` |

**列头 → 类型的映射表**（兜底匹配用）：

| 列头含有关键词 | 推断类型 |
|---|---|
| 名称 / 品种 / 材料 | `name` |
| 材料库 / 编码 / 对照 | `matlib` |
| 参数 / 引用 / 关联 | `param` |
| 单位 | `unit` |
| 数量 / 工程量 / 用量 | `qty` |
| 系数 / 损耗 / 调整 | `coef` |
| 备注 / 说明 | `remark` |
| 单价 / 综合单价 | `price` |
| 金额 / 合价 / 总价 | `amount` |
| 规格 / 型号 / 断面 | `spec` |
| 品牌 / 厂家 / 产地 | `brand` |
| 分组 / 分类 | `group` |

匹配不到就 `text`，**不猜、不报错** —— 猜错比不猜更糟。

---

## 5. 换类型时的数据处理

换类型**不自动转换已有数据** —— 猜错比不猜更糟。只在值明确合规时提示：

| 从 → 到 | 已有数据 | 行为 |
|---|---|---|
| `text` → `qty` | 非数值 | **提示但不拦**，标黄待用户处理 |
| `text` → `param` | 非 URN | **提示但不拦**，这是 `docs/17` 里踩过的坑：存成可读原文会导致联动永不命中 |
| `name` → 其他 | 有文字 | 允许，但**若该列是唯一的 name 列须警告**（章节标题会失去载体） |
| 任意 → `name` | — | 若已存在别的 `name` 列，本列会成为「第二名称列」，章节标题取最左那个 |
| 任意 → 任意 | 合规 | 静默通过 |

---

## 6. 输入输出

| 项 | 内容 |
|---|---|
| 输入 | 工作表名、列字母、类型 key |
| 输出 | `NodeConfig.chapterColTypes` 更新、列头文字可改 |
| 不落xlsx | 类型是节点语义，不是文件内容 |

---

## 7. 边界

| 情况 | 处理 |
|---|---|
| 改第一列/ 第二列的类型 | **拒绝** —— 它们是章节层固定结构，不属于自定义列 |
| 列字母非法 | 回落默认，不抛（脏配置不该让整张表打不开） |
| 类型 key 拼错 | 回落 `text`，回报里标出「未识别」 |
