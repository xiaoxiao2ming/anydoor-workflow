# ooec.outline —— 章节编排

> 状态：**已实现**（当前为数字模式，字符模式待切，见总规格 §5）
> 落点：`src/xlsx/outline.ts` / `outlineAdapter.ts` / `ChapterDialog.tsx` / `useOutlineSlot.ts`

---

## 1. 用途

在 ooec 表里建立章节分级，让章节号自动重排，并提供一个可折叠的目录大纲窗体。

---

## 2. 列结构

| 列 | 内容 | 性质 | 可编辑 |
|---|---|---|---|
| 第一列 | 字符标记 `#` / `##` / `###` / `####` / `#####` / 空 | **唯一真相** | ✅ |
| 第二列 | 自动编号 `1.2.1`（关联联动） | 派生 | ❌ |
| 第三列起 | `name` 列等自定义列 | 业务数据 | ✅ |

> 完整列定义见 [ooec.spec.md §2](./ooec.spec.md)。

---

## 3. 提示词

```
在ooec 材料的第 {工作表} 表上编排章节：

1. 第一列按下列结构写字符标记（# 的个数 = 章节大小，空 = 普通数据行）：
{粘贴章节结构}

2. 第二列的章节号由系统自动重算，不要手写。
   规则：# → 1，## → 1.1，### → 1.1.1；普通行不编号也不打断上级计数。

3. 章节标题文字写在第一个 name 类型列上。

4. 跳级会被自动钳制并提示（例如第一行直接写 ### 会变成 #），
   不要靠写错字符数来试探层级。

完成后打开「审阅 → 章节编排」窗体校验：折叠、升降级、定位是否正常。
```

## 4. 语义细则

### 4.1 跳级钳制

一级下直接出现三级 → 自动钳为二级，并toast 提示。
理由：绝不允许出现 `1.0.0.1` 这类脏编号。

```ts
// 现有实现，勿改
export function normalizeLevels(rows: OutlineRow[]): boolean {
  let prev = 0
  let changed = false
  for (const r of rows) {
    if (r.level > 0) {
      const max = prev + 1            // 上一行是 L，本行最多 L+1
      if (r.level > max) {
        r.level = (max <= 0 ? 1 : max > MAX_LEVEL ? MAX_LEVEL : max) as RowLevel
        changed = true
      }
      prev = r.level
    }
    // level === 0：普通行不改变 prev
  }
  return changed
}
```

**首行的铁律**：`prev = 0`，所以首行 `###` 会被钳成 `#`。
这不是 bug —— 没有父级可挂，钳到一级是唯一正确答案。

### 4.2 第二列的重算时机

| 用户动作 | 第二列怎么办 |
|---|---|
| 拖动行 | 全量重算 |
| 增删行 | 全量重算 |
| 升降级 | 全量重算 |
| 改第一列标记 | 全量重算 |
| 折叠 / 展开 | **不重算**（不动结构，无需写盘） |
| 打开 xlsx | 全量重算，**不读B 列历史值** |

### 4.3 折叠

- 折叠状态**存在行上**（跟着行走），不存全局集合
  —— 存在全局集合会在拖动后错乱
- 折叠时该节点的所有更高级行应同步隐藏（方案 P2，**当前未实现**）
- 窗体提供「折叠全部 / 展开全部」

### 4.4 拖动

- 拖动 = 摘出子树整段再插入（`takeSubtree` + `insertSubtree`），子树跟走是免费的
- 三语义 drop（树上拖拽，方案 P3，**当前未实现**）：

| 拖到节点的位置 | 语义 |
|---|---|
| 上 1/3 | 插到它**前面**（同级） |
| 下 1/3 | 插到它**后面**（同级） |
| 中 1/3 | 变成它的**子级** |

- 普通行（第一列为空）**不可作容器**

## 5. 输入输出

| 项| 内容 |
|---|---|
| 输入 | 字符标记（第一列）、标题文字（name 列） |
| 输出 | 章节号（第二列，重算后写静态值）、目录大纲树 |
| 副作用 | 重算公式、落盘（`commit()`：重算 + 补丁保存 + undo 快照 + 引用对账） |

---

## 6. 边界与坑

| 坑 | 处理 |
|---|---|
| 手改第二列 | 下次重算即被覆盖（设计如此：编号是派生数据） |
| 用户手改过的 B 列历史脏值污染编号 | 打开时**只认第一列**，B 列一律重算 |
| 折叠状态在拖动后错乱 | 折叠状态存在行上 |
| `counters` 未截断导致编号重复 | `counters.length = r.level` 不能省 |
| 树和表格两份状态互同步 | 树每次从 `rows` 全量重建，不做增量 |
| 1000 行性能 | `renumber` O(n) 全量，实测 < 16ms；**不做增量** |
| 公式引用行位置 | 拖动后公式引用需重算（交给既有 DAG 引擎） |

## 7. 验收用例

1. 拖动 `1.2 工程概况` 到 `1 总说明` 之前 → 编号变`1 / 2 工程概况 / 3 编制依据…`，其下 `2.1 地质条件` 自动跟走变 `1.1`
2. 把三级标题拖到一级标题下方 → 自动钳为二级，toast 提示
3. 在第一列填 `###` → 第二列编号立即重排，标题行缩进同步
4. 折叠 `2 管道设计` → 该节点及其所有子行一起隐藏（**P2，当前未实现**）
5. 导出 xlsx 用 Excel 打开：第一列是 `#` 字符、第二列是 `1.2.1` 静态值；改第一列再传回，编号重排正确
6. 1000 行混合标题 + 普通数据，全量重算 < 16ms
