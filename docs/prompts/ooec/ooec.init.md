# ooec.init —— 新建材料表

> 状态：规格已定，未实现

---

## 1. 用途

新建一张 ooec 材料表工作簿，落好默认列骨架，让后续填数据不用先手工搭表头。

---

## 2. 提示词

```
在 ooec 节点上新建一张材料表：

1. 工作表名：{表名，如「主要材料汇总表」}
2. 第一列留空（章节标记列，由用户或后续 ooec.outline 填）
3. 第二列留空（章节号列，系统自动重算）
4. 从第三列起按下列顺序建列，并打上类型：
   {粘贴「列名 = 类型」清单，默认用：
     名称 = name
     材料库 = matlib
     单位 = unit
     数量 = qty
     系数 = coef
     备注 = remark
   }
5. 第一行写表头，字体加粗、冻结首行
6. 不要动用户已有的其他工作表

建完回报：表名、列清单、每列的类型。
```

---

## 3. 默认列骨架

`ooec.init` 的默认产物（用户点名 7 类型里的 5 个 + 材料库）：

| 列 | 列名 | 类型 | 宽 | 对齐 |
|---|---|---|---|---|
| A | （章节标记） | — | 6 | 居中 |
| B | （章节号） | — | 10 | 居中 |
| C | 名称 | `name` | 28 | 左 |
| D | 材料库 | `matlib` | 18 | 左 |
| E | 单位 | `unit` | 8 | 居中 |
| F | 数量 | `qty` | 12 | 右 |
| G | 系数 | `coef` | 10 | 右 |
| H | 备注 | `remark` | 30 | 左 |

A/B 两列**不算自定义列**，它们是章节层的固定结构（见 `ooec.spec.md` §2）。
自定义列从 C 起 —— 正好对上「第二列之后为自定义列」。

---

## 4. 输入输出

| 项 | 内容 |
|---|---|
| 输入 | 表名、列清单（列名 + 类型 key） |
| 输出 | 新工作表 + 表头行 + 列宽 + 冻结 + 列类型配置 |
| 落点 | `NodeConfig.chapterColTypes`（类型不落 xlsx，理由见 `ooec.col.types.md` §5） |

---

## 5. 边界

| 情况 | 处理 |
|---|---|
| 节点已绑定工作簿 | **不新建 sheet**，改为提示用户先解绑 —— 静默覆盖会吞数据 |
| 列名重复 | 自动加后缀 `_2` / `_3`，不报错 |
| 类型 key 不认识 | 回落 `text`（兜底类型），并在回报里标明 |
| 列清单为空 | 用 §3 默认骨架 |

---

## 6. 与既有能力的关系

- 建表 / 写表头 / 冻结 / 列宽 → 复用既有 `WorkbookEditor` 能力，**不新开落盘路径**
- 列类型是本ooec 独有，落`NodeConfig`（见 `ooec.col.types.md` §5 的理由）
