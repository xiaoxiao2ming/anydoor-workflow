# ooec.link —— 联动

> 状态：**已实现**（`docs/15-联动触发规则-结项.md`，规则层已通）
> 落点：`src/xlsx/trigger.ts` / `apply.ts` / `TriggerPanel.tsx`

---

## 1. 用途

定义「外部参数改了 → 什么条件下 → 写本表哪里」的规则。

**不实时**，是规则触发的批量更新。

---

## 2. 提示词

```
给 ooec 材料第 {工作表} 表配联动规则：

规则：当{监听的 URN 或「任何来源」}  {条件}  则  {动作}

逐条列出：
  1. 当{源} {条件} 则 {动作}
  2. ...

配完先干跑预览，回报：
  · 命中规则数、将写入的单元格清单
  · 未命中的规则及原因
干跑不落盘。确认后再真跑。
```

---

## 3. 规则模型

```
当<watch>   <condition>   则   <action>
例：当  管径·设计值  值变化时   则 写单元格 Sheet1!F2
    当  任何来源    无条件      则 重算
    当  任何来源    无条件      则 落盘（去抖 800ms）
```

| 维度 | 取值 |
|---|---|
| **watch** | `change`（任何来源）/ 精确 URN / `node://x#`（前缀）/ `param://`（同 scheme 全部） |
| **condition** | `always` `changed` `gt` `gte` `lt` `lte` `eq` `ne` `between` `outside` `nonEmpty` `empty` `isTrue` `isFalse`（14 种） |
| **action** | `writeCell` `writeRange` `recompute` `commit`（4 种） |
| **priority** | 小的先执行（**写值必须在重算之前**） |
| **debounceMs** | 连续拖动滑块只落盘一次 |

---

## 4. 三条硬语义

用户 2026-10-05 定案，勿改：

| 语义 | 实现 |
|---|---|
| **不实时** | 参数变化只产生变更集，不自动写文件 |
| **规则决定是否更新** | 每条规则有 watch + condition + action |
| **没命中 = 完全不动** | 规则集为空或条件不满足 → **一次 IO 都不发生** |

理由：比「每次都重算」更省、更可控，**更新是我授权的，不是它自作主张的**。

---

## 5. 干跑预览

规则配完**先干跑**，干跑不落盘：

| 干跑回报项 | 内容 |
|---|---|
| 命中规则 | 规则序号 + 条件判定过程 |
| 将写入 | 单元格坐标 + 旧值 → 新值 |
| 未命中 | 规则 + 未命中原因（哪个条件没过） |
| 护栏拦截 | 公式格被保护、类型闸门拦下等 |

---

## 6. 三个关键设计决策

### ① 类型闸门：不同类型族一律算变化

```
空归一(null/undefined/'') → 类型闸门 → 数值容差比较 → 对象 JSON 比对
```

若不先拦类型，`toNum` 会把 `false → 0`、`'1.0' → 1`，
于是 `0 → false`（布尔开关翻转）被误判成「没变」→ 规则不触发，用户改了参数却没反应。

> ⚠ 空归一**必须排在类型闸门之前**：`''` 会因 `toNum('')=null` 落到 str 族，
> 否则 `null → ''` 被误判成「从空变成了字符串」。这个顺序错误在单测里暴露过。

### ② 安全护栏：公式格绝不静默覆盖

写值时若目标格是公式格，**跳过并回报**，不覆盖。
公式是用户写的意图，不是待更新的缓存。

### ③ 执行复用既有 `commit()`

刻意**不新开落盘路径** —— 触发执行复用 `WorkbookEditor` 既有 `commit()`
（重算 + 补丁保存 + undo 快照 + 引用对账），
所以 undo、引用对账、补丁保存全都自动成立。

---

## 7. 输入输出

| 项 | 内容 |
|---|---|
| 输入 | 规则集（watch / condition / action / priority / debounce） |
| 输出 | 规则配置（`NodeConfig`） |
| 执行 | 干跑 → 预览报告；真跑 → 写值 + 重算 + 落盘 |
| 复用 | 引用寻址 `src/ref/urn.ts`、重算 `src/xlsx/recompute.ts`、写值 `setCellByCoord`、落盘 `commit()` |

---

## 8. 边界

| 情况 | 处理 |
|---|---|
| 规则自相矛盾（后写的覆盖先写的） | 按 `priority` 排序，小的先执行，回报执行顺序 |
| 规则环（a依赖 b，b 依赖 a） | 检测到环 → 拒绝执行，回报环路径 |
| 干跑结果与真跑不一致 | 视为 bug —— 干跑与执行必须走同一套判定代码 |
| 联动会改到章节结构列 | **拒绝** —— 章节层只写第一/二列 + `name` 列 |
